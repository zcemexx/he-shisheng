# 贺石生个人主页

这是无需构建工具的静态网站。上传仓库根目录下的 `index.html`、`style.css`、`language-switch.js`、`en` 和 `assets` 文件夹，便可用于 GitHub Pages。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，将本文件夹内容上传到仓库根目录（不要把整个文件夹再嵌套一层）。
2. 在仓库的 Settings → Pages 中，选择 Deploy from a branch，将分支设为 `main`、目录设为 `/ (root)`，保存。
3. 等待 GitHub 完成部署，Pages 页面会显示网站地址。

个人简介与照片由用户提供；网站中的任职、数据和表述应在公开发布前由本人核对。GitHub Pages 在中国大陆的连接质量可能因地区和网络而异，需实地测试。

中文版位于网站根目录，英文版位于 `en/`；中英文页面可相互切换并保留当前章节。

研究方向详情分别位于 `research/` 和 `en/research/`，请一并上传。

研究方向已在首页直接展开；旧版研究页面保留供已有链接访问。
